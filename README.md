### CRMSink



CRM-система, запускаемая на сервере Linux. Система позволяет регистрировать заявки клиентов по ремонту бытовой техники для их систематизации. 



##### Веб-страницы:

* **Лендинг (промо-страница)** - краткое представление преимуществ сервиса, приглашение ко входу и регистрации
* **Страницы авторизации на сервисе** (PostgreSQL)
* **Главная страница** - таблица всех действующих заказов сервиса с возможностью изменить статус, редактировать задачу, перенос в архив.
* **Архив** - просмотр выполненных задач.
* **Журнал действий** - возможность просмотреть все действия над заявками сервиса.
* **Статистика** - простая статистика учёта дохода конкретных сотрудников в конкретный день или месяц.
* **Настройки** - изменение графика работы сервиса, добавление шаблона документов, изменение списка сотрудников и девайсов.



##### Стек проекта:

* **Backend**: Node.js, Express, PostgreSQL;
* **Frontend**: HTML, CSS, JavaScript;
